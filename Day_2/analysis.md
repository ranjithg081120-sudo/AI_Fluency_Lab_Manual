# Analysis: ReAct Tracing, Chain-of-Thought, and Self-Consistency

## Scenario
The Day 1 college fee dataset (CS101 = Rs. 12,000, AI202 = Rs. 18,000, DS303 = Rs. 15,000) is reused here, alongside three pure-reasoning questions requiring no external data: a scholarship instalment calculation, a two-part counting problem, and a height-ordering logic puzzle.

## 1. Paper trace vs agent trace (Part A and B)
The paper trace for "Which is cheaper: CS101+AI202 at 10% off, or all three at 25% off?" required looking up three course fees (CS101, AI202, DS303) and performing three calculations: the discounted total for two courses, the discounted total for three courses, and the difference between them — six actions in total. Running the same question through the real agent (react_trace.py) produced a matching sequence: three get_course_fee calls followed by three calculator calls, reaching the same final answer of Rs. 6,750 cheaper for the two-course option. This confirms the agent's tool-calling behaviour matches a correctly reasoned-out plan, and shows that six tool calls in this case correspond to six separate LLM round-trips, since each action requires the model to decide the next step based on the previous observation.

## 2. Chain-of-Thought comparison (Part C)
Without Chain-of-Thought, the model gave only a final numeric answer with no visible working, and on the multi-step instalment question this occasionally skipped a step (such as forgetting to apply the scholarship before dividing into instalments), producing an incorrect result. With Chain-of-Thought, the model was instructed to number each step and show its calculation, and it correctly worked through the scholarship deduction, the remaining balance, and the per-instalment split in a clear, checkable sequence. The counting and logic-ordering questions were answered correctly under both prompting styles, since they required less arithmetic depth, but the CoT versions were noticeably longer and showed the reasoning explicitly, making errors easier to catch. When a fourth question requiring private course-fee data was added, Chain-of-Thought still reasoned step by step, but over invented numbers, since it has no way to access the real fee data — showing clearly that better reasoning alone cannot substitute for real information the model does not have.

## 3. Self-consistency observation
Running the scholarship instalment question five times at temperature 0.8 produced the correct answer (Rs. 9,562.50) in most runs, with one run occasionally landing on an incorrect value due to a missed step in that particular sample. Taking the majority answer across the five runs recovered the correct result even though not every individual run was accurate. Setting the temperature to 0 makes the model's output deterministic, so all five runs return nearly identical answers — at that point, voting adds no value because there is no variation to vote across. This shows self-consistency is only useful when some randomness (a non-zero temperature) is present, and it exists specifically to guard against the model occasionally slipping on one sampled reasoning path.

## 4. Suitability analysis
For a question needing only careful reasoning over information the model already has, Chain-of-Thought prompting is sufficient and considerably cheaper than running a full agent loop. For a question needing private or real data, plain Chain-of-Thought is not sufficient no matter how well-structured the reasoning is, and a ReAct agent is required so the model can fetch real facts through tools rather than inventing them. Self-consistency adds a further layer of reliability specifically for reasoning-heavy questions, at the cost of running the same question multiple times.

## 5. Conclusion
Direct prompting is fastest but offers no visibility into how an answer was reached and is more likely to skip steps on multi-step problems. Chain-of-Thought improves accuracy and transparency on reasoning tasks by forcing the model to work through the problem step by step, but it remains limited to what the model already knows — it cannot supply facts it was never given. A ReAct agent removes this limitation by interleaving reasoning with real tool calls, allowing it to fetch external or private information and incorporate it into its reasoning before answering. Self-consistency is a complementary technique, useful whenever a reasoning-only question is important enough to justify running it multiple times and taking the majority answer as a safeguard against occasional errors in any single reasoning path.
